# NAVBAT — Online MVP

Bu paket foydalanuvchi web-ilovasi + tashkilot Business paneli + real-time queue backenddan iborat.

## Ishga tushirish
1. Kompyuterga Node.js 18+ o‘rnating.
2. Terminalda loyiha papkasiga kiring.
3. `node server.js` buyrug‘ini bering.
4. Brauzerda `http://localhost:3000` ni oching.
5. Tashkilot paneli: `http://localhost:3000/business`

## Muhim
Bu hozircha MVP/demo server. Production uchun HTTPS, PostgreSQL, haqiqiy SMS/OTP, push notifications, role-based authentication, audit log, backup va cloud deployment qo‘shilishi kerak.

## Hosting
Node.js qo‘llaydigan VPS/Render/Railway/Fly.io kabi serverga joylash mumkin. `PORT` environment variable ishlatiladi.
